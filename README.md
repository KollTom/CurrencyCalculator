# CurrencyCalculator
CurrencyCalculator is a simple JavaFX project I made, to start learning the JavaFX basics.
It uses the [FreeCurrencyAPI](https://freecurrencyapi.com) to get the currency rates, then caches them, and updates them if they are older than 10 minutes

## How to use
On the first start you will be asked to provide the API Key.

![Picture that shows Settings-Screen](https://github.com/KollTom/CurrencyCalculator/raw/settings/assets/images/settings_screen.png "Settings-Screen")

Then you can click the top-left button to save it and get to the Main-Screen. There you can put in your base currency, target currency and amount. As soon as you click the Calculate-Button, it will automatically be converted for you

![Picture that shows Main-screen](https://github.com/KollTom/CurrencyCalculator/raw/settings/assets/images/main_screen.png "Main-Screen")
